# v2 里程碑二期

v2 二期目标是从「可运行」扩展到「可扩展」和「功能完善」。核心是引入插件系统，让第三方可以通过插件接入更多 IM 平台、LLM Provider、Tool，同时增加子 Agent 编排、知识库 RAG、运维增强等能力。

## 整体方向

从 v1 的 inner 实现模式，转向插件化架构。v1 中所有接口保持不变，inner 实现逐步变为默认内置插件，外部插件通过同一套接口注入。Dashboard 也相应增加插件管理、知识库管理等页面。

## 要实现的全部功能

- Dashboard API 服务：基于 Ktor 提供 REST API 和 WebSocket 实时日志
- 管理面板前端：Vue3 + TypeScript 从零搭建 7 个页面
- 插件系统：ClassLoader 隔离、热加载/卸载、插件市场
- 更多 IM 平台：QQ、微信（个人/企业/公众号）、Discord、钉钉、飞书、LINE、Slack
- 更多 Provider：Anthropic、Gemini、DeepSeek、STT、TTS、Embedding、Rerank
- LLM 流式响应：ChatProvider 流式调用 + Agent Runner 逐 chunk 转发，实现打字机效果
- 子 Agent 编排：多 Agent 协作、Handoff、路由分发、链式调用
- 第三方 Agent Runner：桥接 Dify、Coze 等第三方平台
- 知识库 / RAG：文档加载、向量检索、自动注入 Agent
- Dashboard 增强：插件市场、子 Agent 编排视图、知识库管理、全局设置
- 运维增强：Docker 镜像、Prometheus Metrics、健康检查、配置热重载
