# ops — 运维增强

提供生产环境部署和运维所需的能力。

## 容器化

- Docker 镜像构建和发布，支持 `docker-compose` 一键部署
- 多架构支持（amd64 / arm64）
- 数据目录挂载和持久化

## Kubernetes

- Helm Chart 支持，便于 Kubernetes 集群部署
- 支持 ConfigMap 和 Secret 管理配置
- 支持持久卷声明（PVC）保存数据库和日志

## 监控

- Prometheus Metrics 端点暴露：消息吞吐量、LLM 调用延迟、工具调用次数、错误率
- 健康检查端点 `/health`：数据库连通性、平台状态、Provider 连通性
- 优雅关闭：SIGTERM 信号处理，确保进行中的消息处理完成后再退出

## 配置

- 配置热重载：修改配置文件后无需重启即可生效
- 环境变量覆盖：支持通过环境变量覆盖配置文件中的值
- 配置备份与恢复：自动定期备份配置文件，支持恢复到历史版本
