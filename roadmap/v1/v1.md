# v1 里程碑一期

v1 一期目标是搭建一个可以完整运行的 PriestessBot 系统最小闭环。所有功能模块对外暴露接口、内部 inner 实现，不引入插件系统。核心流程是：IM 端收到用户消息 → 经过 9 个阶段的管道处理 → Agent ReAct 循环调用 LLM 和工具 → 返回最终回答。

## 整体架构

项目仅包含核心模块 `imagent-core`，无 API 服务器和前端面板。所有配置以代码中的 inner config 方式管理（`@Serializable` data class + JSON 文件持久化），不需要 Web Dashboard。核心模块使用 Koin 依赖注入管理所有组件生命周期，通过 Channel 事件总线串联 IM 平台和管道调度。

## 要实现的全部功能

- 基础设施：核心生命周期编排、类型安全配置系统、Koin 依赖注入、事件总线、SQLite 持久化
- IM 平台抽象层：定义统一的 Platform 接口，内置 Telegram 和 NapCat（QQ）两个适配器
- 消息管道：实现 9 个阶段的洋葱模型调度，从唤醒检查到最终发送回答
- LLM Provider 抽象层：定义 ChatProvider 接口，内置 OpenAI 和 Ollama 实现
- Agent 循环：实现 ReActRunner，支持 Thought → Action → Observation 循环
- Tool / MCP 体系：抽象 FunctionTool 和 ToolSet，内置 4 个工具，支持 MCP 协议
- Skill 管理：定义 Skill 接口，内置默认问答 Skill
- 会话管理：会话持久化和消息历史存储
